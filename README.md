
# Java Sleep Tracker — анализ записей о сне на Java

**Java Sleep Tracker** — учебное консольное приложение для анализа истории сна по данным из текстового файла. Программа рассчитывает статистику продолжительности и субъективного качества сна, анализирует записи о ночном сне и выводит рекомендации по заранее заданным правилам.

Проект создан в рамках обучения Java и демонстрирует работу с **Java Core, Stream API, Java Time API, ООП, функциональными интерфейсами и JUnit 5**.

> **Важно:** приложение не отслеживает сон автоматически и не является медицинским инструментом. Оценка хронотипа и рекомендации основаны на упрощённых правилах. Отсутствие записи о сне не доказывает бессонницу.

## Возможности

- Загрузка записей о сне из текстового файла.
- Парсинг дат, времени и оценок качества сна (`GOOD`, `NORMAL`, `BAD`).
- Пропуск пустых строк и записей, которые не удалось корректно разобрать.
- Расчёт общего количества сессий сна.
- Определение минимальной, максимальной и средней продолжительности сна.
- Подсчёт сессий с плохой оценкой качества.
- Подсчёт ночей, для которых не обнаружено записи о ночном сне.
- Условное определение преобладающего хронотипа: **«сова», «жаворонок» или «голубь»**.
- Вывод сводной статистики и рекомендаций в консоль.
- Возможность добавлять новые способы анализа через общий интерфейс `SleepAnalysisFunction`.

## Технологии

- **Java Core** (Java 16+; запуск проверен на Java 21)
- **Stream API** — фильтрация, агрегация, группировка
- **Java Time API** — `LocalDateTime`, `LocalDate`, `LocalTime`, `ChronoUnit`
- **Collections Framework** — `List`, `Map`, `Set`
- **ООП и полиморфизм** — отдельные реализации интерфейса анализа
- **Функциональный интерфейс** — `SleepAnalysisFunction`
- **Java I/O / NIO** — чтение файлов и ресурсов
- **JUnit 5** — модульные тесты

Проект не использует Spring, базу данных, Maven или Gradle. JAR-файлы JUnit находятся в каталоге `lib/`.

## Формат входных данных

Каждая строка файла описывает одну сессию сна:

```text
дата_начала время_начала;дата_окончания время_окончания;качество
```

Формат даты и времени — `dd.MM.yy HH:mm`, значения качества — `GOOD`, `NORMAL`, `BAD`.

Пример:

```text
01.10.25 23:15;02.10.25 07:30;GOOD
02.10.25 23:50;03.10.25 06:40;NORMAL
03.10.25 14:10;03.10.25 15:00;NORMAL
03.10.25 23:40;04.10.25 08:00;BAD
```

В репозитории уже есть пример данных: `src/main/resources/sleep_log.txt` (13 записей).

**Для корректности анализа ночей** записи рекомендуется располагать в хронологическом порядке. При ошибочном формате строки она пропускается.

## Архитектура

Основная логика разделена на несколько компонентов:

- **`model`** — данные о сессии сна, типы качества и хронотипа, результат анализа.
- **`analyzer`** — семь независимых алгоритмов расчёта статистики.
- **`util`** — разбор входных строк и вспомогательные операции с ночными интервалами.
- **`app`** — загрузка данных, запуск анализаторов и вывод отчёта.

Каждый анализатор реализует интерфейс:

```java
@FunctionalInterface
public interface SleepAnalysisFunction {
    SleepAnalysisResult analyze(List<SleepingSession> sessions);
}
```

Благодаря этому новую метрику можно добавить отдельным классом и зарегистрировать в `SleepTrackerApp`, не изменяя существующие анализаторы.

## Как запустить

**Требования:** установленный JDK 16 или новее. Компиляция и запуск проверены на **Java 21**.

### Через терминал (Linux/macOS)

Из корня репозитория выполните:

```bash
mkdir -p build/classes
javac -encoding UTF-8 -d build/classes $(find src/main/java -name "*.java")
java -cp "build/classes:src/main/resources" ru.yandex.practicum.sleeptracker.app.SleepTrackerApp
```

Команда использует пример `sleep_log.txt` из ресурсов проекта.

### Анализ другого файла

Передайте путь к файлу первым аргументом:

```bash
java -cp "build/classes:src/main/resources" \
  ru.yandex.practicum.sleeptracker.app.SleepTrackerApp \
  /путь/к/sleep_log.txt
```

### Через IntelliJ IDEA

1. Откройте репозиторий как Java-проект.
2. Укажите установленный JDK (рекомендуется Java 21).
3. Проверьте, что `src/main/java` помечен как **Sources Root**, а `src/main/resources` — как **Resources Root**.
4. Запустите `main()` класса `ru.yandex.practicum.sleeptracker.app.SleepTrackerApp`.
5. Чтобы использовать другой файл, укажите путь к нему в **Program arguments**.

## Тестирование

В репозитории находятся **114 методов `@Test` в 14 тестовых классах JUnit 5**. Они покрывают:

- расчёт статистических показателей;
- обработку пустых списков и граничных значений;
- определение хронотипа;
- подсчёт ночей без зарегистрированного сна;
- обработку ночных интервалов;
- разбор входных записей;
- классы модели и работу приложения.

Исходный код и тестовые классы успешно **скомпилированы на Java 21**. Полный запуск всех тестов через JUnit Runner отдельно не подтверждён.

Поскольку в проекте нет `pom.xml` или `build.gradle`, для запуска тестов в **IntelliJ IDEA** необходимо подключить JUnit 5 из каталога `lib/` и пометить `src/test/java` как **Test Sources Root**.

Конфигурация `.github/workflows/api-tests.yml` ссылается на повторно используемый workflow Яндекс Практикума. Она не является самостоятельно настроенным процессом сборки.

## Ограничения

- Это консольный анализатор файлов, а не автоматический трекер или медицинская система.
- Хронотип определяется по упрощённым порогам времени сна и пробуждения, а не по клинической методике.
- Ночи без записей могут учитываться как бессонные, хотя данные могли быть просто не внесены.
- Для части расчётов предполагается хронологический порядок записей.
- Неверные строки пропускаются без отдельного отчёта о причинах.
- Данные не сохраняются в базе, нет REST API и графического интерфейса.
- Правила рекомендаций заданы непосредственно в коде приложения.
